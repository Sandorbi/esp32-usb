02 / Commands

115200 · 8N1

The sequence lasts about 4.38 seconds. Outputs turn off after 5 seconds without a command. STATUS resets that timer; this page never polls automatically.

03 / Board log

Ready when you are.
First connection? Start here.
  1. Upload the existing PlatformIO firmware to the board.
  2. On your phone, open this page over HTTPS in Chrome. Connect the ESP32 with your data cable or OTG adapter.
  3. Tap Connect board, select CP2102, and accept the USB permission prompt.
  4. Tap STATUS. Look for “Sequence: IDLE” and “Safety: OFF”. Then try START and STOP.

If no device appears, check the data cable and phone USB/OTG settings. Close other serial apps. On a computer, select Web Serial and close the PlatformIO serial monitor.

Disconnect closes the connection; it does not send STOP. Use STOP first to switch the LEDs off immediately. Otherwise, the firmware timeout still applies.

Commands travel over the cable. No account, no server relay.
