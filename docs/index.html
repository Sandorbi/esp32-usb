NodeMCU ESP-32S / CP2102 / 115200 baud

Connect the board using a USB data cable, then tap Connect board.

Commands

115200 · 8N1

A turns on immediately, B at 400 ms, C at 900 ms. All three turn off at 2 seconds. START sends START_SEQUENCE with the selected intensity.

Safety demonstration

Checked every 200 ms

Set a simulated sensor reading manually. The ESP32 checks it every 200 ms and turns all LEDs off if the reading is 2500 or higher.

For the demo, set 1000, press START, then set 3000 while the LEDs are on. The sensor command only updates the input; the board performs the cutoff automatically. Set a value below 2500 before starting again. Values are simulated units, not temperature.

Connection and wiring
  1. Upload the capability-test firmware with PlatformIO.
  2. Wire LED A to GPIO16, B to GPIO17, and C to GPIO18. Each LED needs its own 330 Ω series resistor and a cathode connection to GND.
  3. On your phone, open this page over HTTPS in Chrome. Connect the ESP32 with your data cable or OTG adapter.
  4. Tap Connect board, select CP2102, and accept USB permission.
  5. Tap STOP and check for “OK: STOP; all LEDs OFF” in the board log. Then try START.

If no device appears, check the cable and phone USB/OTG settings. Close other serial apps. On a computer, select Web Serial and close the PlatformIO serial monitor.

Disconnect closes the connection; it does not send STOP. Use STOP for immediate shutdown. A running sequence still ends at 2 seconds, and the board continues checking its sensor independently.
