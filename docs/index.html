Hot Flash Simulation

Three timed outputs, cable control, and an automatic safety cutoff.

Connection

Disconnected

NodeMCU ESP-32S / CP2102 / 115200 baud

Connect the board using a USB data cable, then tap Connect board.

Commands

115200 · 8N1

A turns on immediately, B at 400 ms, C at 900 ms. All three turn off at 2 seconds. START sends START_SEQUENCE with the selected intensity.

Safety demonstration

Checked every 200 ms

Set a simulated sensor reading manually. The ESP32 checks it every 200 ms and turns all LEDs off if the reading is 2500 or higher.

Move the slider and release to send the value (0–4095). For the demo, send a value below 2500, press START, then release the slider at 2500 or higher while the LEDs are on. The board performs the cutoff at its next safety check. Lowering the value does not restart the sequence. Values are simulated units, not temperature; check the board log for confirmation.

Board log

Ready when you are.

Disconnect closes the connection; it does not send STOP. Use STOP for immediate shutdown. A running sequence still ends at 2 seconds, and the board continues checking its sensor independently.
